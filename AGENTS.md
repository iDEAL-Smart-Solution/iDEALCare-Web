# iDEALCare-Web Agent Instructions

## Application layout

- Content rendered through the shared `<Outlet />` must fill the available width of `.app-main`.
- Do not center a primary page wrapper or impose an arbitrary `max-width` on outlet content. Keep spacing aligned with the main content padding; constrain individual forms or reading blocks only when the page requires it.
- Place global patient actions such as notifications in the top application header, not in the role sidebar.
